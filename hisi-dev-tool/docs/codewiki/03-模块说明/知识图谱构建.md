## 1. 模块概述

### 1.1 职责定义

把 Java / Python / TypeScript-JavaScript-Vue 源码解析为 Neo4j 图（方法、类、入口点、调用、桥接、SQL、数据模型），生成描述与向量，再聚合出架构现状（模块、分层、领域、热点、变更频率）。

### 1.2 职责边界

| 做什么 | 不做什么 | 由谁负责 |
|---|---|---|
| 任务入队、串行执行、状态落 SQLite | 任务持久化队列、重试 | `KgGenerationQueue`（内存队列） |
| Java：JavaParser 静态解析 + 调用解析 | 依赖 jar 内类型解析 | 无（`buildSolver` 只含源码目录，见问题 3.5） |
| Python：ANTLR4 解析 + 框架路由识别 | Python 依赖包解析 | 无 |
| TS/JS/Vue：调用外部 `codegraph` CLI | 自研前端 AST | `codegraph/FrontendAstParser` 仅服务绑定构建 |
| 描述 + 向量生成 | Embedding/LLM 调用 | `neo4j/service/EmbeddingService`、`LLMDescriptionService` |
| 架构聚合 | 架构诊断与建议 | `archdiagnosis` 包 |
| 调用链/桥接/DSM 查询端点 | 语义/向量检索 | `neo4j/controller/*SearchController` |
