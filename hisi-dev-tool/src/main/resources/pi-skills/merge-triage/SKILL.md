# 合并影响分析

输入是 diff 结果（新增/修改/删除的文件与关键改动）。

## 影响面

- 按「接口/数据/状态机/逻辑」分类每个改动，标出受影响的入口（HTTP 路由、定时任务、MQ 消费）。
- 风险分级：破坏性接口变更 > 数据/状态变更 > 内部逻辑。

## 测试范围

- 覆盖所有变更文件对应模块的回归用例；
- 接口变更必须有接口级用例；数据变更必须有迁移与回滚说明；
- 用不到的项目模块不要圈进范围。

输出按调用方要求的 schema；拿不准的类归属先用工具查。
