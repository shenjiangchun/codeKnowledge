# HiSi 业务流分析 Skill

## 目的
分析接口的完整业务调用流程

## 使用场景
用户提供一个URI或接口名，需要了解完整的调用链路

## 步骤
1. 使用 `kg_call_chain_by_key` 获取入口方法的调用链
2. 使用 `kg_method_detail` 获取关键方法的详细信息
3. 使用 `kg_callees` 分析下游依赖
4. 使用 `kg_callers` 分析上游调用方
5. 组织成完整的业务流程图

## 输出格式
- **入口方法**: Controller层的接口定义
- **调用链路**: 完整的方法调用序列（含层级缩进）
- **关键节点**: 重要的分支和决策点
- **外部依赖**: 数据库、MQ、HTTP调用
- **流程图**: Mermaid格式的时序图
