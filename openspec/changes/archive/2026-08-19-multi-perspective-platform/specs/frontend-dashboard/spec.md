# 前端多切面仪表盘：需求规格

## 目的
构建架构师多切面分析平台的前端 UI，支持 Tab 布局切换 6 个切面（架构仪表盘、调用链、DSM 矩阵、热点分析、领域/DDD、跨服务拓扑）+ 生成中心智能面板。首页 5 秒内回答"架构有没有问题"。

## 范围
### 本次范围
- Tab 布局框架（复用已有 KnowledgeGraphView.vue 的 el-tabs 模式）
- 架构仪表盘首页（架构评分 + KPI 卡片 + 循环依赖洞察 + 领域模块图，节点=业务领域非包名）
- DSM 依赖矩阵（ECharts heatmap）
- 热点分析 Treemap（ECharts treemap）
- 领域边界视图（G6 force layout + 领域分组着色）
- 跨服务拓扑图（G6 force layout + bridgeType 着色）
- 生成中心合并面板（上下文感知：选中方法→测试建议，选中模块→重构建议）
- 爆炸半径结果展示（集成到调用链切面 + 独立弹窗）
- 空状态引导（无 KG 数据时引导构建）
- 构建进度条 + 上次结果降级展示
- 前端 API 层新增 6 个 API 函数 + TypeScript 类型

### 非目标
- 移动端适配
- 暗黑模式（可后续迭代）
- 国际化

## ADDED Requirements
### Requirement: 首页 5 秒回答"架构有没有问题"
系统 MUST在用户打开仪表盘首页后，5 秒内展示架构健康摘要 + Top 3 风险项。

#### Scenario: 首次打开已有 KG 数据的仪表盘
- 前提：项目已完成构建 + 聚合
- 当：用户导航到 /knowledge-graph（默认 Tab 为仪表盘）
- 则：页面顶部展示一句话状态：如"架构评分 78/100 ↗ +3 本月"
- 并且：4 个 KPI 卡片（严重违规数、耦合评分、热点模块数、趋势方向）
- 并且："立即关注"列表展示 Top 3 风险（每条含具体类名 + 问题描述 + 动作按钮）
- 并且：所有数据在页面加载后 2 秒内渲染完成（不含网络请求时间）

#### Scenario: 失败处理
- 当：项目未构建 KG
- 则：展示空状态引导页："尚未构建知识图谱" + [选择项目] + [开始生成] 按钮 + 预计耗时说明

### Requirement: DSM 矩阵展示模块依赖
系统 MUST以热力图展示 N×N 模块依赖矩阵，高亮循环依赖和分层违规。

#### Scenario: 打开 DSM 矩阵切面
- 前提：项目有 12 个模块
- 当：用户点击 [DSM] Tab
- 则：ECharts heatmap 渲染 12×12 矩阵
- 并且：单元格颜色强度 = 依赖数量（白=0，深蓝=高）
- 并且：循环依赖的对称单元格用红色边框标记
- 并且：分层违规单元格（controller→mapper）用红色背景标记
- 并且：点击单元格展示"谁依赖了谁"的具体方法列表

### Requirement: 热点 Treemap 展示文件级风险
系统 MUST以 Treemap 展示文件级热点，面积 = 文件代码行数，颜色 = 风险分（红=高/绿=低）。

#### Scenario: 打开热点分析切面
- 前提：项目有 500 个文件，Top 热点为 OrderService.java（riskScore=0.92）
- 当：用户点击 [热点] Tab
- 则：ECharts treemap 渲染文件热力图，OrderService 方块最大且最红
- 并且：点击方块展示详情面板（复杂度/变更次数/入度/出度/风险分解）
- 并且：右上角可切换视图：Treemap / 散点图（复杂度 vs 变更频率）/ 列表

### Requirement: 领域边界视图展示检测结果
系统 MUST以力导向图展示自动检测的领域边界，每个领域用不同颜色分组。

#### Scenario: 打开领域切面
- 前提：Louvain 检测到 5 个领域
- 当：用户点击 [领域] Tab
- 则：G6 v5 force layout 渲染领域图，5 个领域用 5 种颜色区分
- 并且：组间连线粗细 = 跨域调用强度
- 并且：置信度标记（>0.8 用实线边框，<0.8 用虚线边框）
- 并且：点击领域展开内部类的详细列表
- 并且：左上角显示 LLM 命名的领域名（"订单域""支付域"）

### Requirement: 生成中心面板上下文感知
系统 MUST根据用户当前选中的上下文（方法 vs 模块）自动切换建议内容。

#### Scenario: 选中方法后打开生成中心
- 前提：用户在调用链切面选中了 OrderService.placeOrder
- 当：用户点击 [生成中心] Tab
- 则：面板展示爆炸半径概要 + LLM 生成的测试建议列表（每条含场景描述 + 优先级）
- 并且：[复制为 prompt] 和 [导出] 按钮可用

## 兼容性与外部契约
- 所有新 API 函数遵循已有 knowledgeGraphApi 模式（request.get/post + 类型参数）
- TypeScript MethodNode 接口新增 5 个 optional 字段（不影响已有组件）
- G6 v5 与已有 dagrejs 共存（各切面各自选择渲染引擎）

## 验收矩阵
| 需求/场景 | 验证方法 | 可证伪的失败表现 |
|-----------|---------|----------------|
| 首页 5 秒展示摘要 | E2E：加载仪表盘 → 截屏 → 断言 Top 3 风险可见 | 首页空白或只有 loading |
| DSM 矩阵渲染 | 组件测试：传入 12 模块数据 → 断言 12×12 格子渲染 | 单元格数 ≠ 144 |
| 热点 Treemap 渲染 | 组件测试：传入 20 条热点数据 → 断言 Treemap 方块可见 | 方块面积为 0 |
| 领域力导向图 | 组件测试：传入 5 领域数据 → 断言 5 种颜色分组 | 只有 1 种颜色 |
| 空状态引导 | 组件测试：projects=[] → 断言引导文字可见 | 展示空白页 |
| 构建进度条 | 组件测试：status=RUNNING → 断言进度条渲染 | 进度条不显示 |

## 已确认决策
| 决策项 | 选择 | 批准人/日期 | 影响的需求 |
|--------|------|------------|-----------|
| 前端图渲染库 | G6 v5（WebGL） | 用户 / 2026-08-11 | 领域视图、跨服务拓扑 |
| DSM 渲染 | ECharts heatmap | 用户 / 2026-08-11 | DSM 矩阵 |
| Treemap 渲染 | ECharts treemap | Agent 调研 + 用户确认 | 热点分析 |
| 生成中心布局 | 合并为一个上下文感知面板 | 用户 / 2026-08-11 | 生成中心 |
| 路由模式 | Tab 模式（单路由 /knowledge-graph） | 用户 / 2026-08-11 | 所有切面 |
| 跨语言视图 | 分语言 + "全部"聚合 | 用户 / 2026-08-11 | 仪表盘、DSM |
| 首页 3 指标原则 | 架构评分 + 严重违规 + 热点模块 | UX 调研结论 | 仪表盘首页 |

## 显式未知项
- G6 v5 在 500+ 领域节点时的实际帧率（理论 WebGL 60fps，需实测）
