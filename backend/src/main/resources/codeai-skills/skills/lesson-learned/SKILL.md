# 经验学习技能

## 技能概述

本技能从历史问题和解决方案中学习，积累项目经验知识库，为开发者提供问题诊断和解决方案建议。

## 适用场景

- 遇到技术问题需要诊断
- 寻找类似问题的解决方案
- 学习项目历史经验
- 避免重复踩坑

## 核心能力

### 1. 问题诊断

根据错误信息、日志、代码片段诊断问题根因：

- 异常堆栈分析
- 日志模式匹配
- 代码逻辑检查
- 环境配置检查

### 2. 知识检索

从知识库中检索相关经验：

- 问题相似度匹配
- 解决方案推荐
- 最佳实践建议
- 相关文档链接

### 3. 经验积累

自动记录问题解决过程：

- 问题描述记录
- 解决方案归档
- 效果反馈收集
- 知识图谱更新

## 常见经验分类

### 数据库问题

| 问题类型 | 常见原因 | 典型解决方案 |
|----------|----------|--------------|
| 连接超时 | 连接池配置不当 | 调整连接池参数 |
| 死锁 | 事务顺序不一致 | 统一事务访问顺序 |
| 慢查询 | 缺少索引 | 添加合适索引 |
| 主键冲突 | 自增ID用尽 | 使用雪花算法 |

### 服务问题

| 问题类型 | 常见原因 | 典型解决方案 |
|----------|----------|--------------|
| 内存溢出 | 对象未释放 | 检查资源关闭 |
| CPU飙升 | 死循环/频繁GC | 优化算法/调整内存 |
| 线程阻塞 | 锁竞争 | 使用并发工具类 |
| 服务超时 | 下游服务慢 | 增加超时/降级 |

### 配置问题

| 问题类型 | 常见原因 | 典型解决方案 |
|----------|----------|--------------|
| 启动失败 | 配置项缺失 | 补充必要配置 |
| 端口冲突 | 端口被占用 | 更换端口/终止进程 |
| 认证失败 | 密钥不匹配 | 检查密钥配置 |
| 环境差异 | 配置不一致 | 统一配置管理 |

## 问题诊断流程

```
1. 收集信息
   ├── 错误信息/异常堆栈
   ├── 相关日志片段
   ├── 环境信息
   └── 复现步骤

2. 分析定位
   ├── 匹配已知问题模式
   ├── 分析调用链路
   ├── 检查相关配置
   └── 确定问题范围

3. 解决方案推荐
   ├── 检索知识库
   ├── 相似度排序
   ├── 展示解决方案
   └── 提供操作指南

4. 效果跟踪
   ├── 收集反馈
   ├── 更新成功率
   └── 优化知识库
```

## 最佳实践

### 1. 及时记录

遇到问题解决后及时记录，避免遗忘。

### 2. 结构化描述

使用统一格式记录，便于检索和复用。

### 3. 持续更新

根据反馈持续优化解决方案。

### 4. 分类标签

合理使用标签，提高检索效率。
