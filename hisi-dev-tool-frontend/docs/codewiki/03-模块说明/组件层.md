## 3. 写法约定

以下约定来自对现有组件的通读：

| 约定 | 说明 |
|------|------|
| 脚本形式 | 一律 `<script setup lang="ts">` |
| 属性 | 用 `interface Props` 声明后传给 `defineProps`，可选属性用 `withDefaults` 给默认值 |
| 事件 | `defineEmits<{ (e: 'name', payload: 类型): void }>()` 具名元组写法 |
| 对外暴露 | 需要被父组件或测试直接调用的方法用 `defineExpose` |
| 样式 | `<style scoped>`；布局骨架（`AppLayout`）用非 scoped 的全局重置 |
| 图标 | `main.ts` 把 `@element-plus/icons-vue` 的全部图标注册为全局组件，模板里可直接写 `<el-icon><Plus /></el-icon>` |
| Markdown | 统一用 `utils/markdown.ts` 的 `renderMarkdown`（marked + DOMPurify 净化）后 `v-html` |
| 图 | ECharts 与 Mermaid 按需在各组件内 `import`，初始化前先 `dispose` 旧实例 |
| 布局计算 | 把布局算法写成不依赖 DOM 的纯函数（`dagLayout.ts`、`threeRingLayout.ts`、`flowDagLayout.ts`），模板只负责渲染 |
