# HiSi 根因分析 Skill

## 目的
结合日志和代码知识图谱进行深度根因分析

## 使用场景
用户提供异常堆栈或错误日志，需要追踪到代码层面的根本原因

## 步骤
1. 解析异常堆栈，提取关键类名和方法名
2. 使用 `log_query` 查询更多上下文日志
3. 使用 `kg_method_detail` 获取异常方法的代码信息
4. 使用 `kg_affecting` 分析该方法的影响范围
5. 使用 `hybrid_search` 搜索相关的历史问题和解决方案
6. 综合分析得出根因

## 输出格式
- **异常链**: 从表面异常到根本原因的完整链路
- **代码定位**: 具体出错的代码行和方法
- **触发条件**: 什么条件下会触发此问题
- **影响评估**: 该问题影响的范围和严重度
- **修复方案**: 推荐的修复方案（含代码示例）
- **预防措施**: 避免类似问题的建议
