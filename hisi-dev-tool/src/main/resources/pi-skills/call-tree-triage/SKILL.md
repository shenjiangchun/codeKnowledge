# 调用链精准定位

输入包含入口方法、异常类型与消息、以及预取的调用链上下文。

## 方法

1. 从入口开始沿调用链向下（kg_callees_tree），在每一层判断「异常最可能从这里产生」。
2. 对可疑方法读实现（kg_method_detail / 源码），重点看异常抛出点、参数校验、状态依赖。
3. 根因要落到「具体方法 + 具体行 + 为什么」；证据不足时给出候选并按可能性排序，不要硬猜一个。
4. 每个结论附证据（哪个工具、查到的什么）。

输出按 phase2 schema 的 JSON。
